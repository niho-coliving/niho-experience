# 料金・日時・言語・取消・天候の標準案

最終更新：2026-10-19（担当3）。**すべて提案で、オーナー承認まで適用しない。** 既存チャネルで販売中の条件を、この文書だけを根拠に変更しない。
販売条件の正本はNIHO共通基盤の商品・開催枠データとし、公開サイトは共通APIの値を表示する。

## 予約前に必ず見せる項目

旅行者がCheckoutへ進む前に、次の項目を英語で確認できるようにする（[design-brief.md](../design-brief.md)）。

- 価格：円、税込、単位（大人1名・子ども1名・1グループ）、合計、追加料金
- 開催日時：JSTの日付・開始時刻・所要時間
- 人数：最少催行人数、1予約の上限、子どもの年齢と同伴条件
- 言語：下の区分のどれか
- 販売・提供主体の名前
- 取消・天候中止・遅刻の扱いの要約と全文へのリンク
- 予約方式：即時確定か、提供者の承認待ちか（承認までの時間）

## 料金

金額は提供者とオーナーが決める。担当3は次の点を確認する。

- 同じ商品の価格をチャネル間（niho-experience、NIHOapp、OTA）でどう揃えるか。OTAとの契約に価格を揃える条項があるかはオーナーが契約書で確認する。
- 子ども料金を設定するか、何歳からか。
- 貸切制の場合の最少料金（例：2名分）を表示するか。
- 料金に含むもの（材料、飲み物、持ち帰り品）と含まないもの（交通費、追加の飲み物）。
- 割引、クーポン、紹介報酬は販売条件の変更にあたるため、30日検証では使わない。

## 開催枠

- 販売開始時に、4〜8週間先までの開催枠を共通基盤に登録する。提供者が確実に開催できる日だけを登録する。
- 複数チャネルで同じ枠を売る場合、在庫を管理する人と、他チャネルの枠を閉じる手順を商品ごとに決める（[operations.md](operations.md)）。
- 受付締切を決める。例：前日18時（JST）まで、2日前まで。

## 言語の区分

| 表示 | 意味 |
| --- | --- |
| English | 提供者が最初から最後まで英語で案内できる |
| English and Japanese | 英語と日本語が混ざる。英語の流暢さは人によって異なる旨を併記する |
| Japanese, with an English-speaking guide | 提供者は日本語で話し、同席する通訳・ガイドが英語にする |

## 取消

| 型 | 旅行者による取消 | 想定する商品 |
| --- | --- | --- |
| A：24時間前まで無料 | 開始24時間前までは全額返金。以降は返金なし | P-01（既存チャネルで表示中の条件）、P-02 |
| B：7日前まで無料 | 開始7日前までは全額返金。以降は返金なし | 材料を事前に用意する工芸体験（P-04・P-05） |
| C：提供者の既存条件 | 提供者が他チャネルで使っている条件（14日前など）に揃える | P-03 |

どの型でも共通にする案：

- 提供者・NIHO側の都合で中止した場合は全額返金し、別日を提案する。
- 最少催行人数に満たない場合は、開始の24時間前（型Bは3日前）までに連絡し、全額返金または別日の提案をする。
- 連絡のない不参加は返金しない。
- 返金の判断は表示された販売・提供主体が行い、問い合わせの一次受付はNIHOが担う（[NIHO特商法表記](https://niho.life/legal/tokushoho)の記載に合わせる）。

共通APIで型A〜Cと最少催行を表現できるかは担当2に確認する。

## 天候・交通機関

| 区分 | 案 |
| --- | --- |
| 屋内（P-01・P-02・P-04・P-05） | 雨天でも開催する。開始の3時間前の時点で、気象庁が鎌倉市に暴風警報または特別警報を出している場合は中止する |
| 屋外を含む（P-03の境内見学、R-01） | 小雨は開催。開始の3時間前の時点で、鎌倉市に大雨・暴風の警報または特別警報が出ている場合は中止する。境内の見学だけ短縮する場合の扱いは提供者と決める |
| 交通機関 | JR横須賀線または江ノ島電鉄が運休し、参加者が来られない場合は、参加者からの連絡で全額返金または別日へ振り替える |
| 中止時 | 予約時の連絡先へ判断時刻から30分以内に連絡する。全額返金または別日への振替を選べる |

## 遅刻

- 開始から15分までは待つ。予約時の案内で、遅れる場合の連絡方法を伝える。
- 15分を過ぎた場合は、途中から参加できるか提供者が判断する。参加できない場合の返金はしない（取消の型に従う）。
- 貸切制の商品で提供者が別の遅刻ルールを持つ場合は、それを表示する。

## 子ども・アルコール・食事

- 子どもは保護者の同伴を条件とし、受け入れる年齢と料金を商品ごとに表示する。包丁・火・熱い焙煎機を使う商品は、作業に参加できる年齢を別に書く。
- アルコールを出す場合は20歳未満に提供しない旨を表示する。
- 食物アレルギーに対応できない場合は「不向き」に明記する。対応できる食事制限（ベジタリアン等）があれば具体的に書く。
- アレルギー等の記入欄は健康情報を含みうる。予約処理の中だけで扱い、計測・ログへ送らない。
