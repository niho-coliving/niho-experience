# 運営分担（一枚まとめ）

最終更新：2026-10-19（担当3）。NIHOが支援する作業と、提供者に残る作業を商品の一生に沿って並べる。
「提案」の分担はオーナーと提供者の合意後に確定する。

## 役割

| 役割 | 担う人 |
| --- | --- |
| オーナー | NIHO kamakuraの運営責任者。販売条件・掲載・外部への連絡の承認 |
| NIHO運営 | NIHOのコミュニティマネージャー等。編集、問い合わせの一次受付、予約の確認連絡 |
| 提供者 | 体験を開催する人。既存拠点の商品（P-01・P-02）ではNIHO運営が兼ねる |
| 販売・提供主体 | 申込画面に表示される事業者。品質・提供・返金判断の責任を負う（[NIHO特商法表記](https://niho.life/legal/tokushoho)） |
| 担当1・2・3 | サイト・デザイン、API・NIHO連携、商品・集客（[execution-plan.md](../execution-plan.md)） |

## NIHOが支援することと提供者に残ること

| NIHOが支援する | 提供者に残る |
| --- | --- |
| 英語原稿の編集、写真の撮影手配、掲載作業の代理入力 | 内容の事実確認、写真の同意、掲載の承認 |
| 問い合わせの一次受付、予約確認の連絡、リマインド | 予約の承認、開催、当日の安全管理 |
| 在庫の同期、他チャネルの記載のそろえ | 開催できる日の申告、中止の判断 |
| 集客と計測 | 販売者としての本人確認・口座登録（口座未接続の場合。[architecture.md](../architecture.md)） |

## 問い合わせの目標時間（提案）

| 種類 | 目標 |
| --- | --- |
| リクエスト予約の承認 | 24時間以内（既存ページの表示と同じ） |
| 予約前の質問への初回返信 | 24時間以内。開始48時間以内の予約に関する質問は4時間以内 |
| 中止の連絡 | 判断から30分以内 |

承認・返信にかかった時間は[funnel-measurement.md](../growth/funnel-measurement.md)の「提供者対応時間」として測る。
